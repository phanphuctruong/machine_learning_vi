# Machine Learning bằng tiếng Việt

Khóa Machine Learning từ nền tảng đến nâng cao, học qua notebook. Mỗi buổi kể một câu chuyện từ dữ liệu thật, giải thích từng bước và từng tham số, nhiều hình minh họa. Code viết bằng tiếng Anh, giải thích bằng tiếng Việt. Dữ liệu lấy từ scikit-learn nên chạy được ngay, không cần tải thêm.

## Cách học

Bấm **Mở trên Colab** ở bảng dưới, chạy lần lượt từng ô. Không cần cài đặt gì.
